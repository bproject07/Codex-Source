# Support

This repository is an independent fork of
[`openai/codex`](https://github.com/openai/codex) and is not an official OpenAI
support channel.

## Start here

- For downloads, source builds, checksum verification, updates, and common
  installation errors, read [INSTALL.md](INSTALL.md).
- For one-shot, JSONL, HTTP, OpenAI SDK, and network examples, read
  [API.md](API.md).
- For security boundaries and private vulnerability reports, read
  [SECURITY.md](SECURITY.md).

## Where to ask

- **Fork-specific bugs:** use the bug report form in this repository.
- **Fork-specific feature ideas:** use the feature request form.
- **Questions about building or using this fork:** use the question form.
- **Security vulnerabilities:** follow [SECURITY.md](SECURITY.md) and report
  privately. Never disclose a vulnerability in a public issue.
- **Unmodified upstream Codex behavior:** search or report it in
  [`openai/codex`](https://github.com/openai/codex/issues).
- **OpenAI accounts, subscriptions, billing, or hosted services:** use the
  [OpenAI Help Center](https://help.openai.com/).

Maintainers provide support on a best-effort basis and cannot promise response
times or compatibility with every local modification.

## Before posting

Search existing issues, reproduce with the latest commit when practical, and
include the commit identifier, operating system, installation or build method,
CPU architecture, `codex-raw --version` output, and minimal reproduction steps.
Remove credentials, tokens, private prompts, personal data, local paths, and
unrelated logs before submitting. Never attach `~/.codex-raw/auth.json`.
