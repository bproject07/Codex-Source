# Contributing to Codex-Source

Contributions to this fork are welcome. Before opening an issue or pull request,
please read:

- the [contribution guide](docs/contributing.md);
- the [contribution licensing policy](docs/CLA.md);
- the [`codex-raw` implementation notes](codex-rs/raw-cli/README.md) for Raw
  changes;
- the [Code of Conduct](CODE_OF_CONDUCT.md); and
- the [security policy](SECURITY.md) for private vulnerability reports.

This repository is an independent fork of
[`openai/codex`](https://github.com/openai/codex). Contributions submitted here
are reviewed and maintained by this fork's maintainers, not by OpenAI.

User-facing changes must keep [README.md](README.md),
[INSTALL.md](INSTALL.md), [API.md](API.md), and rendered CLI help consistent.
Before submitting, inspect the complete diff for credentials, tokens, private
prompts, local infrastructure details, generated build output, and sensitive
logs.
